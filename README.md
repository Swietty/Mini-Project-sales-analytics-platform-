# Mini-Project-sales-analytics-platform-
Sales Analytics Platform: Eine umfassende Python-Lösung für die Datenanalyse. Beinhaltet objektorientiertes Design (OOP), Datenbereinigung mit Pandas/NumPy, algorithmische Optimierung und Visualisierung von Verkaufsberichten.

# Sales Analytics Platform

## Projektbeschreibung
Dieses Projekt analysiert Verkaufsdaten, berechnet wichtige KPIs, implementiert eigene Sortier- und Suchalgorithmen und erstellt Visualisierungen.

## Installation
pip install -r requirements.txt

## Benötigte Bibliotheken: 
pandas, numpy, matplotlib

## Nutzung
python main.py
